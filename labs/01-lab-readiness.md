## Tasks
- [ ] Inventory any existing direct installation before removing or changing it.
- [ ] Consult the official requirements for the exact Secret Server version.
- [ ] Record the requirements source URL and date checked.
- [ ] Check the supported operating system, database, web prerequisites, and virtualization constraints.
- [ ] Decide whether the available host can support the planned guest resources.
- [ ] Draw the planned lab components and connections.
- [ ] Use fictional accounts and isolated test targets.
- [ ] Define a rollback or rebuild procedure.
- [ ] Record blockers: installer, license, permissions, resources, or unsupported configuration.

Do not uninstall an existing deployment until its purpose, data, and recovery needs are understood. Changes on a work-managed device must follow the employer's lab policy.

## Success criteria
A documented, supported design and a clear list of available resources and blockers. Installation is a later lab.
