# Delinea Secret Server Lab

Personal study notes, hands-on labs, and troubleshooting practice for Secret Server Engineer preparation.

## Start here
1. Review the [study roadmap](study/ROADMAP.md).
2. Complete [Lab 01: readiness and architecture](labs/01-lab-readiness.md).
3. Copy the [lab log template](notes/LAB-LOG-TEMPLATE.md) for each exercise.

GitHub is the notebook and version history; Secret Server runs in a separate supported lab environment. These materials do not provide a license, installer, or official exam questions.

## Working method
Study the relevant Delinea University module, perform an isolated exercise, record the result, explain failures, and verify recovery. Use the official documentation for your exact product version before running commands or installing components.

## Repository hygiene
Use fictional lab accounts. Never commit passwords, access tokens, private keys, license keys, database backups, employer/client information, or proprietary training materials. A private repository and .gitignore are not substitutes for checking what you commit.
